# Robosign

A.K.A. Radish sign.

Tool for making station signs.

## Usage

Open the site then make it.

## Dependencies

Robosign depends on the following:

- Typst for building
- Wikimedia Commons for some SVG assets
- Jsdelivr for the typst compiler and fonts
